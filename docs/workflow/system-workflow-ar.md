# آلية عمل نظام OSCAR

**قواعد التشغيل المعتمدة: 2 أكتوبر 2026.** المرجع: [خطة المشروع](../../PLAN.md)، الأقسام 3 و4. هذا وصف للسلوك المطلوب، وليس تأكيدًا لتنفيذ كل الوظائف. المواعيد بتوقيت بغداد، والعملة USDT فقط.

## 1. الحساب والرصيد

التسجيل بالإيميل وكلمة المرور، والتفعيل برابط بريدي. رمز الدعوة اختياري ولا يتغير صاحب الدعوة بعد التسجيل. دخول الأدمن بالإيميل وكلمة المرور، دون تسجيل إداري عام.

مصادر الرصيد: إيداعات، مكافآت مقبولة، وعمولات إحالات. **المتاح** يستخدم حسب الأهلية؛ **المحجوز للسحب** يظل مملوكًا للموظف، لكنه لا يستخدم مجددًا. مكافآت المهام المعلقة ليست رصيدًا متاحًا.

## 2. الإيداع

**المسار:** عنوان مخصص للموظف تحت تحكم الشركة؛ تحويل USDT عبر TRON؛ رصد والتحقق؛ إضافة المبلغ مرة واحدة.

| لو حصل الآتي | النظام يتصرف كالتالي |
| --- | --- |
| تحويل صحيح وناجح ومؤكد إلى العنوان المخصص | يضيف المبلغ الفعلي؛ إيداع 100.37 يضيف 100.37 USDT. |
| التحويل غير مؤكد أو الرصد متأخر | يستكمل الفحص دون إضافة رصيد بالتخمين. |
| شبكة أو عملة أو عنوان غير مطابق | لا يعتمد كإيداع صحيح؛ رقم التحويل وحده لا يثبت ملكيته. |
| تكرر إشعار التحويل، أو جُمعت الأموال في محفظة الشركة الرئيسية | لا يضيف رصيدًا جديدًا؛ التجميع تحويل مستقل. |

الإيداع يعمل طوال الأسبوع؛ **دون انتظار 72 ساعة أو رفض إداري**. الإضافة بعد تحقق النظام وليست ضمانًا لظهورها فور التحويل. لا يوجد حد تجاري أدنى أو أقصى معتمد. تعديلات الرصيد الإدارية حركات منفصلة، لا تعديلات على سجل TRON.

## 3. السحب ومراحله

يثبت عنوان السحب مرة واحدة برابط بريدي، وتغييره لاحقًا للأدمن فقط. يُقبل الطلب عند صحة العنوان والأهلية وكفاية الرصيد وعدم وجود طلب نشط. الحدود الأولية **16–500 USDT**، والرسوم **21% للجميع**؛ تُحفظ شروط الطلب عند قبوله.

**مثال:** طلب 100 يحجز 100؛ يستلم الموظف 79، والرسوم 21. الشركة تتحمل تكلفة الشبكة، ولا تخصم 100 أخرى عند النجاح. الحجز يستهلك الأموال غير الإحالية أولًا، ثم العمولات المؤهلة.

| حالة الطلب | ماذا يحدث؟ |
| --- | --- |
| مجدول | المبلغ محجوز؛ موعد الإرسال بعد 72 ساعة محتسبة. |
| رفض الأدمن قبل بدء الإرسال | يعود كامل الحجز بمصادره الأصلية مرة واحدة. |
| زيادة الجدولة | تضاف ساعات محتسبة للموعد الحالي مع السبب؛ لا تعاد الـ72 ساعة من البداية. |
| حان الموعد | إرسال تلقائي عند استيفاء شروط التنفيذ، دون موافقة إدارية. |
| قيد الإرسال أو انتظار التأكيد | الطلب نشط والمبلغ محجوز. |
| النتيجة غير معروفة | تراجع العملية الأصلية؛ لا استرداد أو تحويل بديل بالتخمين. |
| نجاح مؤكد | تسوية الحجز وإنهاء الطلب؛ يسمح بطلب جديد. |
| فشل نهائي مؤكد دون دفع المبلغ | فك الحجز مرة واحدة؛ يسمح بطلب جديد. |

**الوقت:** كل ساعات الاثنين للجمعة تُحسب، وليس ساعات المهام فقط؛ السبت والأحد مستبعدان. الجمعة 12 ظهرًا تصبح الأربعاء 12 ظهرًا: 12 + 24 + 24 + 12 ساعة. انتهاء العد بداية السبت يؤجل الإرسال للاثنين؛ تأكيد تحويل مُرسل يستمر في العطلة.

لا يقبل طلب ثانٍ أثناء الطلب النشط، حتى من جهاز آخر أو مع نتيجة مجهولة. بعد الاكتمال أو الرفض/الفشل الآمن وفك الحجز يمكن الطلب فورًا؛ **دون انتظار 24 ساعة**.

## 4. الباقات والإحالات

- باقة نشطة واحدة؛ الشراء والترقية يخصمان **كامل سعر الباقة المطلوبة**. رصيد 5 وباقة 20 يعني إيداع 15 ثم شراء بـ20؛ السعر السابق لا يخفض الشراء. تُستهلك العمولات غير المحجوزة أولًا.
- التفعيل فوري بعد نجاح الشراء، دون موافقة إدارية أو استرداد للاشتراك. الترقية للأعلى تبدأ مدة جديدة؛ تجديد نفس الباقة ممنوع قبل انتهائها. تعديلات الإدارة لا تغير شروط الاشتراك القائم.
- المدة الأولية 365 يوم عمل؛ الغياب يفوّت المكافأة ولا يمد الاشتراك. الشراء قبل 6 مساءً يحتسب يوم العمل الحالي، وعند 6 أو بعدها يبدأ يوم العمل التالي؛ شراء العطلة يبدأ الاثنين. الانتهاء بداية اليوم التالي لآخر يوم عمل محسوب.
- نسب L1–L5 الأولية **12%، 6%، 4%، 2%، 2%**. عمولة الشراء/التجديد على السعر الكامل؛ الترقية على الفرق الموجب. سابقة بـ10 وجديدة بـ20: الشراء 20، لكن عمولة L1 هي 1.20.
- العمولة تتطلب اشتراكًا نشطًا وعدم الحظر وقت الشراء. لا عمولات بأثر رجعي للمجاني أو المنتهي أو المحظور، ولا إعادة توزيع لنسبة غير المؤهل.
- المستويات نسبية: محمد دعا أحمد، وأحمد دعا ياسمين؛ ياسمين L2 لمحمد وL1 لأحمد.

## 5. المهام والقرارات

مهمة واحدة يوميًا من الاثنين للجمعة، **12 ظهرًا حتى قبل 6 مساءً**؛ لا مهام بالعطلة. الكود المفعّل يفتح المهمة المشروطة به؛ إيقافه يمنع الاستخدامات الجديدة فقط، مع استمرار الموعد والأهلية العادية.

| الحالة | النتيجة |
| --- | --- |
| صورة وإقرار بتنفيذ المهمة | انتظار مراجعة؛ تثبيت مبلغ المكافأة دون إضافة رصيد. |
| قبول الأدمن | إضافة المكافأة مرة واحدة؛ قبول نهائي دون تراجع لاحق. |
| رفض الأدمن | رفض نهائي؛ لا مكافأة أو إعادة تقديم. |
| ترقية أو انتهاء الباقة أو الحظر بعد الإرسال | العمل الصحيح قابل للقبول بمكافأته الأصلية؛ الحظر يستمر. |
| تعديل الصورة المعلقة | قبل القرار وداخل الموعد الأصلي، دون مكافأة ثانية. |

الصورة خاصة بحد 5 MB، وحفظ 30 يومًا على الأقل. المعلقة تستثنى من الحذف؛ السجلات تبقى بعد تنظيف الصور. تغيير الباقة لا يسمح بمهمة ثانية بنفس اليوم.

| تغيير عنوان السحب قبل الإرسال | إلغاء المجدول وفك حجزه؛ طلب جديد للعنوان الجديد، دون تغيير وجهة القديم. |
